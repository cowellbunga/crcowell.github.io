Program Reflection#

Growth Across Core Competencies

The MGIST program has given me repeated opportunities to work through the full-scale of spatial projects: defining problems, organizing data, selecting methods, implementing tools, and communicating results. The database and web hosting work I completed using ArcGIS Server and Postgres, the modeling and analytics projects that combined raster and vector workflows, and the programming efforts that automated analysis and reporting have all contributed to a more integrated view of what it means to be a geospatial professional. I also learned a lot about project management and development.

Technical Skills and Tools

Over the course of the program, I have become more comfortable designing and managing geodatabases, standing up services on ArcGIS Server, and using SQL and Python to work directly with spatial data - this is not something I was previously familiar with. Projects that relied on custom scripts, automated report generation, and web applications pushed me to write cleaner, more modular code and to think carefully about how end users will interact with the tools I build. I am leaving the program with a suite of new tools and new skills that make me feel more prepared for day-to-day work and more capable of adapting to new platforms and libraries.

Professional Perspective

Many of the projects highlighted in this portfolio involved collaboration with instructors, partners, or hypothetical stakeholders. These experiences reinforced how important it is to balance technical rigor with clear communication and realistic expectations about data, timelines, and uncertainty. I have gained a better sense of how geospatial tools can support decisions in fields ranging from natural resource management to infrastructure planning, and how to design workflows that others can understand and maintain.

Next Steps

Looking ahead, I plan to continue building on the foundation established in MGIST by deepening my experience with cloud-based architectures, open-source tools, and more advanced spatial modeling techniques. I am particularly interested in projects that connect field data collection, analytical workflows, and web-based communication tools into a cohesive system. The projects in this portfolio represent a starting point for that work and a reminder of how much is possible when spatial thinking is combined with solid technical skills.
